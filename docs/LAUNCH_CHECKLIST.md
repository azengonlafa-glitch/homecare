สถานะตอนนี้: ใช้เป็นเดโมหรือทดสอบในครอบครัวได้ **ยังไม่ควรเปิดให้คนนอกครอบครัวใช้กับข้อมูลสุขภาพจริง** จนกว่าจะทำข้อ 1 เสร็จ

## 1. ต้องทำก่อนเปิดจริง (สำคัญที่สุด)

### 1.1 ซ่อนข้อมูลสุขภาพจากคนในบ้านให้ฐานข้อมูลบังคับจริง
- **ปัญหา:** ข้อมูลสุขภาพของแต่ละคน (โรค แพ้ยา ยา ค่าที่วัด บันทึกการกินยา) อยู่ในตาราง `home_items` ที่ทุกคนในบ้านอ่านและแก้ได้ สวิตช์ "ไม่แชร์", สิทธิ์แก้ไข และรายชื่อคนที่ห้ามแก้ ทำงานแค่บนหน้าจอ คนขออนุญาตแก้คำขอเป็น "อนุมัติ" ให้ตัวเองได้
- **แผนที่ตกลงไว้:**
  1. แยกข้อมูลแต่ละคนเป็น 2 ส่วน: ส่วนที่ทุกคนในบ้านเห็น (ชื่อ อายุ เพศ รูป ค่าความเป็นส่วนตัว) กับส่วนสุขภาพที่ฐานข้อมูลคุมสิทธิ์อ่าน/แก้
  2. เปลี่ยนค่าความเป็นส่วนตัวได้เฉพาะเจ้าของ
  3. คำขออนุญาต: เจ้าของข้อมูลเท่านั้นที่อนุมัติได้
  4. ย้ายข้อมูลเดิมบนเซิร์ฟเวอร์ด้วย SQL ที่ทดสอบแล้ว
  5. แอปแยก/รวมข้อมูลให้อัตโนมัติ คนไม่มีสิทธิ์เห็น "ข้อมูลถูกซ่อน"
  6. เอาแอปขึ้นก่อน แล้วค่อยรัน SQL
- **ต้องตัดสินใจ:** บันทึกอาการ (journal) ควรซ่อนตามสวิตช์ "ไม่แชร์" ด้วยไหม หรือให้ทุกคนในบ้านเห็นเหมือนเดิม
- ใครทำ: Claude เขียนโค้ดและ SQL · คุณรัน SQL และ merge

## 4. แจ้งเตือนกินยา: เปลี่ยนจากทุก 5 นาทีเป็นทุก 1 นาที
ในโค้ดแก้แล้ว (`supabase/med_push.sql`) บนเซิร์ฟเวอร์ต้องรันบรรทัดนี้ใน SQL Editor:

```sql
select cron.alter_job((select jobid from cron.job where jobname = 'med-dose-reminders'), schedule := '* * * * *');
```

ผล: แจ้งเตือนเด้งช้าสุดประมาณ 1 นาทีหลังถึงเวลา (เดิมช้าสุด 5 นาที) เซิร์ฟเวอร์ถูกเรียกวันละ 1,440 ครั้ง (เดิม 288) ยังอยู่ในโควตาฟรีของ Supabase (500,000 ครั้ง/เดือน)
